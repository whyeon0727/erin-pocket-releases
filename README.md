# 에린 주머니 PC 앱

에린 주머니 길드 사이트와 함께 사용하는 Windows PC 앱의 설치 파일 배포 저장소입니다. 앱의 소스 코드나 사용자 설정은 이 저장소에 포함하지 않습니다.

설치 파일은 이 저장소의 [최신 릴리스](https://github.com/whyeon0727/erin-pocket-releases/releases/latest)에서 받으세요. 다운로드한 파일의 이름과 SHA-256은 해당 릴리스 안내와 함께 확인할 수 있습니다.

현재 앱은 자동 업데이트를 지원하지 않습니다. 새 버전이 나오면 기존 앱을 종료하고 새 설치 파일을 실행하세요. 기존 인증 및 주머니 설정은 유지됩니다.

이 배포 파일에는 상용 코드 서명 인증서가 없습니다. 보안 프로그램이 차단하거나 경고하면 무시하거나 예외 처리로 우회하지 말고 탐지 내용을 개발자에게 알려주세요.
